原版動態＋SVG 互動推文 / 蔣介石傳

本次採用原網站 390px 手機版取樣：字型、構圖、肖像、照片與內文沿用原始畫面。首屏 GIF 按原動畫參數取樣；SVG 不使用 JavaScript，提供選單、五年份切換、三人物標注、三家庭關係切換、照片放大與原版導讀開關。

此為針對推文的混合最佳化，不是原網站功能 1:1 的移植。游標追蹤、聲音、滾動觸發無法保留。GIF 會循環播放；正文主要使用原版畫面圖片，所以文字不能直接選取或在排版工具內逐字修改。需改稿時應修改原網站後重新取樣；純文字稿附於包內。

預覽：解壓後用瀏覽器打開“本地预览.html”。assets 資料夾保持原位置。點擊 MENU、年份、照片、人物和閱讀卡片，測試打開與關閉。

導入：用支持 SVG/HTML 原始碼的排版工具導入“公众号导入源码.html”。不要把 SVG 直接當普通圖片上傳，可能失去互動。遠端圖片目前由公開 GitHub Pages 托管，發布前需將 GIF、WebP 圖片轉存至公众号素材庫，替換每一個 image 的 href 與 xlink:href 為素材地址。

公众号編輯器可能過濾 animate、set、viewBox、href，微信客戶端也可能表現不同。必須先存草稿，在微信手機預覽中檢查 GIF、切換、展開後高度、返回與所有圖片。本次僅完成標準瀏覽器測試，未在你的公众号草稿中驗證，不承諾直接複製就能發布。

如 WebP 上傳不支持，可使用 package 中 JPG/PNG 兼容素材或由素材工具轉碼；文字內的歷史照片與書封保持來源和授權。原網站與 GitHub Pages 維持可用。
