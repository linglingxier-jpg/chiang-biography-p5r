# P5R 美术研究与改版规格

研究日期：2026-10-10。研究对象为 P5/P5R 的官方站点、真实游戏界面，以及开发团队公开访谈。第一版的红黑配色、星形和摄影拼贴已经成立，但规则网格、水平菜单、平滑淡入、统一字重和矩形弹窗，使它更像现代编辑设计网站。改版需要改变视觉组织和交互状态。

## 参考与可信度

1. [日本 P5R 官网](https://p5r.jp/)：实际访问截图。重点观察红色箭头碎片、金边、混排日文字块、星芒、人物叠压和不规则按钮。当前站点首先显示重制版推广层，不能把推广层当作原始首页全部内容。
2. [欧美 P5R 官网](https://persona.atlus.com/p5r/)：作为宣传网站的排版与入口参考。
3. [Famitsu 对 CEDEC+KYUSHU 2017 开发讲座的现场报道](https://www.famitsu.com/news/201711/13145540.html)：P5 UI 的设计方法。团队将 UI 提升为作品形象的主角；通过白线引导视线，通过布局、角度与明度变化解释层级，在大胆视觉中保持信息传递。
4. [Persona Central 转载的 Famitsu 美术负责人访谈译文](https://personacentral.com/persona-5-interview-ui-design-sound-music/)：偏好平涂、红色主色与黑白文字、操作后迅速出现的菜单。译文属于二手传递，和实际界面截图交叉核对。
5. [P5R 官方杂志美术访谈译文](https://personacentral.com/persona-5-royal-character-designer-interview/)：Royal 的主题包含华丽感；人物肖像加强光泽、双色轮廓光与动态姿势。此项属于人物美术方法，不能直接推断所有游戏菜单都使用金色。
6. [真实 P5 菜单截图及分析](https://medium.com/@kinga.olszewska/interface-so-good-that-people-make-cosplay-of-it-persona-5-ui-controversial-yet-brilliant-ac1ec4b95229)：大块人物剪影、异体剪贴字、粗轮廓、细密网点与选中条。
7. [装备菜单截图及分析](https://www.findmanblog.net/entry/2020/12/30/174818)：成组命令、斜切白色标头、红色活动区和深色非活动区。

检索中的一张结果虽标注 Persona，却实际显示 Metaphor 的 PARTY/FOLLOWER 等界面，已从依据中排除。Behance 的 P5R Webdesign Concept 标明是同人概念，不能当作官方 Royal 网站。

## 视觉语法：基于实物截图的观察

### 1. 轮廓先于纹理

游戏界面缩小后仍能认出大面积黑色人物剪影、白色负空间和红色选区。细密网点、星星只是第二层。第一版以规则两栏和照片框为轮廓，缺乏这种可辨识剪影。

改版：首屏使用贯穿画面的斜向黑色切面，人物图像进入不规则外框；白色轮廓与红色侧影制造切出感。装饰放在正文与按钮下层。

### 2. 字体像拼起来的，而不是统一排出来的

主要字标和命令菜单常出现字宽、大小、倾角、基线与底板差异。不是每个字都随机旋转，而是同一条命令具有整体前进方向，局部字形打破秩序。

改版：中文书名逐字设置比例与倾角，配黑白错位外轮廓；英文短词采用独立剪贴块。正文保持稳定字形与水平排版。禁止旋转整个长段落。

### 3. 红黑白承担不同的信息职责

黑色建立舞台与遮罩，白色突出可操作内容，红色强调活动或冲突区域。Royal 的金色用于少量版本气质和边线，不作为无处不在的背景渐变。

改版：改为更直接的猩红、近黑与白纸；活动菜单显示白色标题与红色折角，未活动菜单退到黑色。金色只放在关键字标、副标和版本细节。

### 4. 星形具有尖锐、多层、越界的特征

第一版的圆滑四角 Unicode 星芒偏精致编辑设计。参考中的五角星、镂空多重轮廓和锋利箭头更像漫画爆发线。

改版：手绘 SVG 多层星形、折线与速度线，控制数量；以大形状支撑构图，少量小星补充节奏。

### 5. 菜单应有角色和状态

菜单不是一排等距链接。主选择与次选择的大小、角度、亮度明显不同，活动状态改变形状和位置，同时维持可读信息。

改版：制作可开合的全屏命令菜单，采用错落斜向命令块与右侧说明；鼠标悬停、键盘焦点和触摸选中拥有一致的状态反馈。网站菜单内容仍是读者真正需要的栏目。

### 6. 动效是切入与定格

参考菜单体现迅速切入、错位叠层、短促回弹与最终定格。第一版的全站同一套缓慢淡入没有这种节奏。

改版：100–280ms 的入口和选中反馈，进入时先显示大形状再显示文字；阅读弹窗采用黑色切入背景与纸页定格。内容立即可操作，减少动态效果模式下停止动画。无需等待式片头。

## 页面映射

| 场景 | 第一版问题 | 改版动作 |
| --- | --- | --- |
| 首屏 | 规则两栏、四字统一黑体、普通照片框 | 剪贴四字标、英文异体字块、白黑粗轮廓、折角人物舞台、速度线 |
| 导航 | 普通水平网站导航 | 保留便捷入口，新增全屏错落命令菜单 |
| 阅读切口 | 杂志式水平表格 | 三组错位斜切命令板，选中轮廓和右侧箭头明显改变 |
| 年份 | 单个旋转矩形 | 尖角白红选中块、分层年份字标与短促切换 |
| 阅读弹窗 | 普通白色 dialog | 不规则外层、黑色标头、白色阅读页，保留稳定正文 |
| 章节过渡 | 规则矩形色块 | 斜向交接与条状章节标牌，构成有方向的视觉路线 |

## 改版验收

- 首屏缩为缩略图时，仍有字标与人物切面的鲜明轮廓。
- 去掉星形和网点后，字体、构图和菜单仍能表达所研究的视觉语法。
- 首页、命令菜单、阅读弹窗三个不同层级都有明确设计。
- 不直接使用游戏角色、原始菜单贴图或游戏 Logo 作为成品资产。
- 中文四字书名可读，长文不倾斜，按钮实际可点击。
- 360–1920px 无意外横向溢出；键盘与减少动态效果可用。
- 自动性能与可访问性结果属于技术验证；设计奖项品质仍需视觉评审，不能用分数替代。
